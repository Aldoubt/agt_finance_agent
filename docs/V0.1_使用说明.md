# AGT Finance Agent V0.1 使用说明

## 1. 启动

发布包必须保持整个 `AGTFinanceAgent-v0.1.0` 文件夹完整，不要只单独复制 EXE。

双击：

```text
AGTFinanceAgent-v0.1.0.exe
```

## 2. 选择输入目录

选择一个包含本批采购原始资料的文件夹。V0.1 至少需要一张 PDF 发票；图片可以包括：

- 商品实物照片
- 淘宝/天猫等购买凭证截图
- 可选的独立支付凭证截图

文件不要求按顺序摆放，也不要求四类材料全部存在。

## 3. 自动分析

选择目录后软件自动完成：

- PDF 发票解析
- 商品行恢复
- 图片类型判断
- 购买凭证 OCR
- 购买凭证与发票匹配
- 高置信实物图自动匹配

首次处理一批图片时 OCR 可能需要几十秒。

## 4. GUI 复核

自动分析完成后进入“AGT Finance Agent - 实物图人工复核”。

主要操作：

- 左侧查看实物图
- 旁侧查看对应购买凭证
- 滚轮缩放、拖拽平移、双击适应窗口
- 右侧选择该照片对应的一个或多个商品
- 同一发票有多个商品时可使用“同发票商品全选”
- 点击“保存选择并下一张”
- 所有选择都会自动保存

一张实物图可以对应多个商品。

## 5. 生成最终归档

点击：

```text
生成最终归档…
```

软件会先显示总金额、发票数量、商品数量、实物图覆盖率、购买凭证覆盖率、支付凭证覆盖率和待复核照片数量。

确认后选择输出位置。最终生成：

```text
总金额/
├── 01_商品名_金额元.pdf
├── 02_商品名_金额元.pdf
├── ...
├── 实物图.docx
└── 采购统计.xlsx
```

## 6. V0.1 验收基线（2026 年 4 月样本）

- PDF 发票：15/15
- 商品行：20
- 输入图片：30
- 实物照片候选：15
- 购买凭证：15
- 购买凭证匹配：15/15
- 人工复核后实物图真值：15/15
- 商品实物图覆盖：20/20
- 商品购买凭证覆盖：20/20
- 总金额：1918.79
- 最终归档：15 PDF + 1 DOCX + 1 XLSX

## 7. 数据与工作区

双击软件运行时，中间分析状态默认保存在：

```text
%LOCALAPPDATA%\AGTFinanceAgent\workspaces\
```

最终财务归档只会写入用户在 GUI 中明确选择的输出目录。
