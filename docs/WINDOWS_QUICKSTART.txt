AGT 采购报销材料整理 · V0.2 交互预览版

开始使用
1. 解压整个压缩包。不要只复制 EXE，保留旁边的 _internal 文件夹。
2. 双击“开始整理.bat”，或双击 AGTFinanceAgent.exe。
3. 第一次可以点“查看示例”，用虚构材料走完四步。
4. 点“开始整理”处理自己的资料：放入材料 → 核对清单 → 确认照片 → 预览导出。

准备材料
- 从 QQ 等邮箱下载的发票 PDF，文件名乱码、数字或未命名都可以，不必改名。
- 收货后拍商品实物。合照可以对应多个商品；只有快递外箱时请补拍里面的商品。
- 淘宝等订单截图有就添加。独立支付凭证是选填项。
- 资料不齐可以先保存，下次从首页继续整理。

你会得到
按总金额命名的文件夹，里面是顺序命名的发票 PDF、实物图.docx、采购统计.xlsx。
Excel 保持原有八列，图片和截图由你确认对应的商品。

重要操作
- 核对发票和商品金额，然后确认清单。
- 照片可多选商品；“确认关联”后立即保存。
- 订单截图与支付截图也可以人工选择对应商品。
- “预览导出”显示缺失材料和真实文件名；完成后点“打开文件夹”。
- 相同金额的另一批材料请另选保存位置，不会自动混进旧文件夹。

这是 Windows 交互预览版。先用示例熟悉操作，再用一小批自己的材料试用。
反馈时请说明卡在哪一步、点击了什么、看到的提示；截图可遮住个人票据信息。
